# T20 World Cup Cricket Analytics Dashboard

An interactive Power BI dashboard for analyzing T20 World Cup cricket data using Power BI, DAX, Power Query, and data visualization.

## Project Overview

This project analyzes T20 World Cup data from 2014 to 2026, covering 230 matches, teams, players, batting performance, bowling performance, toss decisions, venues, and match results.

## Dashboard Pages

- 🏠 Home
- 🏆 Tournament Overview
- 📅 Match Analysis
- 📣 Team Analysis
- 🏏 Batting Analysis
- 🎯 Bowling Analysis

## Key Features

- Tournament-level statistics
- Match and toss analysis
- Team performance analysis
- Batting statistics
- Bowling statistics
- Player performance analysis
- Dynamic filters and slicers
- Interactive Power BI visualizations
- DAX-based calculations

## Technologies Used

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization
- Cricket Analytics
